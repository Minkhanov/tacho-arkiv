The problem

AI agents are still in the logbook era.

What was it allowed to do?The limits live in the agent vendor's dashboard. Anyone with admin access can change them.
What did it actually do?The log is a row in the vendor's database: editable, losable, gone when the vendor is.
Is this request real?The fuel station sees an API call. It cannot check anything without calling the vendor.
